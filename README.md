# Matrix Internet Cybersecurity V3

Standalone static landing page. Open `index.html` for a local preview. The site includes its images and IBM Plex fonts. No dependencies or build step are required.

## GitHub Pages

1. Extract the ZIP and commit its contents to the root of your chosen branch. Keep `index.html`, `.nojekyll` and the other files and folders at the same level.
2. In the repository, open **Settings → Pages**. Set **Source** to **Deploy from a branch**, select the branch you committed to and choose **/(root)**.
3. Save and use the URL shown under Pages once deployment completes.

[GitHub Pages publishing documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Prototype forms

The consultation and sample report forms open prefilled drafts in the visitor's email app. Sending an email requires the visitor to send that draft. Automated submissions, CRM integration and delivery of the sample PDF require a live integration.

The page carries a `noindex` directive. The IBM Plex font licences are in `assets/fonts/`.
